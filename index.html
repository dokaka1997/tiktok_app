ToolHay

A self-hosted tool for preparing short-form videos and publishing them to the operator's own social media accounts.

What it does

ToolHay is a private, self-hosted pipeline used by its operator to prepare short-form video content and publish it to social media accounts that the operator owns. The workflow is:

  • Prepare — translate the caption, generate a Vietnamese voice-over, render subtitles and a channel logo onto the video.
  • Review — the operator checks the finished video, title and description in a web dashboard.
  • Publish — the finished video is uploaded to the operator's own connected accounts on TikTok, YouTube and Facebook, either immediately or at scheduled times.

Use of the TikTok API

ToolHay uses the TikTok Content Posting API for a single purpose: to upload video files that the operator has prepared to TikTok accounts the operator owns and has explicitly connected through TikTok's official authorisation flow. It does not browse, scrape, collect or analyse other users' content, followers or messages, and it does not post to any account that has not been deliberately connected by its owner.

Access

ToolHay is an internal operations tool and is not offered as a public sign-up product. There is no registration form; access is provisioned by the operator.
